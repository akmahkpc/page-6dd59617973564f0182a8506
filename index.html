导入与连接步骤

1. 在用户中心复制 KUS 机场订阅地址，确认格式与客户端匹配（Clash、V2Ray 或 Sing-box）。

2. 打开客户端的订阅或配置管理，选择从 URL 导入，粘贴链接并更新节点列表。

3. 测速后选择延迟较低的节点；办公可选香港或新加坡，游戏可优先 IPLC 线路。

4. 开启系统代理或 TUN 模式，并启用规则分流：国内直连、跨境走代理，避免消耗无用流量。

5. 连接后查看延迟与流量面板。若证书或规则报错，先升级客户端到当前稳定版，再重新更新订阅。

完成以上步骤即可日常使用 KUS VPN 加速。套餐页按钮均指向本客户端区域，方便先选端再导入。

常见问题 FAQ

KUS 官方客户端应该从哪里下载？

请在本页客户端选择区按系统选取 Clash、ClashX、Shadowrocket、Stash 或 Sing-box 等常用端。下载后回到用户中心复制订阅并导入。KUS 不通过第三方网盘分发安装包。

机场订阅导入失败时如何处理？

检查链接是否完整、客户端是否为较新版本，并确认订阅类型与客户端一致。可更换网络后再次更新，或改用备用 Clash / Sing-box 配置。旗舰版与团队版可通过优先工单排查。

各套餐分别支持几台设备同时在线？

基础版 3 台、旗舰版 5 台、团队版 20 台。超出上限时，较早建立的连接可能被断开。同一账号不建议在过多终端同时开启 TUN。

流量用完或高峰时段会怎样？

套餐流量用尽需等待下一周期或升级。普通线路在极端高峰可能拥塞；旗舰版 IPLC 与团队版 VIP 节点更适合会议和游戏。客户端内可随时查看剩余流量。

如何联系客服以及退款如何申请？

请通过官网工单提交问题。旗舰版提供 7x24 优先工单，团队版有专属客户经理。新用户在未大量消耗流量时，可按用户中心规则申请退款，以当时公示条款为准。

KUS 节点与流媒体解锁如何理解？

节点包含香港、日本、新加坡、美国西海岸等区域。旗舰版侧重原生流媒体与 IPLC 游戏线路。解锁效果会随内容平台策略变化，建议以当前节点实测为准，并保持客户端规则更新。
